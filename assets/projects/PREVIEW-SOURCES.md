# Project preview sources

Both silent, looping thumbnail videos are encoded at 320 × 180, 24 fps, H.264
baseline / yuv420p with MP4 faststart. They play at the source speed.

- `generative-dynamics-preview.mp4`: the complete 20-second Unitree G1 hardware
  demonstration from [GenerativeDynamics](https://hhhhzl.github.io/generative-dynamics/).
  Original source: <https://hhhhzl.github.io/generative-dynamics/media/hardware_twogo_g1.mp4>.
  Encoded from the previously downloaded `hardware_twogo_g1.mp4` asset used by
  the earlier version of this personal website.
- `tennis-buddy-preview.mp4`: seconds 4–28 of the existing `tennis-buddy-demo.mp4`,
  showing ball collection. Original project:
  <https://z4ziad.github.io/2026-01-07-tennis_buddy/>.
  Original video: <https://z4ziad.github.io/assets/video/tennis_buddy.mp4>.
  The full demonstration remains available through the thumbnail link and Demo link.

Posters remain visible when JavaScript is unavailable or reduced motion is enabled.
The preview Play/Pause button allows an explicit choice; playback pauses when the
preview leaves the viewport or the tab is hidden.
